后台总览

后台总览 ​

一、进入后台 ​

安装完成并跑过 php bin/migrate.php 后，访问：

text
https://你的域名/admin/

用安装向导里创建的店主账号登录。

结尾斜杠不能省

请访问 /admin/ 而不是 /admin。不带斜杠时浏览器会把页面里的相对资源算成 /assets/...，导致后台 JS 全部加载失败、页面不跳登录页。各部署教程的规则里都带了 301 补斜杠，正常情况下会自动跳转。

二、角色 ​

角色显示权限
owner店主全部功能，含操作日志、账号管理
店员店员日常运营功能，看不到操作日志

安装向导创建的第一个账号就是店主。首次登录若仍是初始密码，系统会提示尽快修改，见账号与安全。

三、左侧菜单一览 ​

分组菜单用途
概览数据概览订单数、销售额、待发货等统计
商品商品管理增删改商品、类型选择、发货配置
商品分类管理分类编号与名称
交易订单管理查单、改状态、发货、后台备注
用户用户管理查看 / 停用账号
用户评价管理审核前台评价
设置站点设置站点文案（存数据库，即时生效）
设置运费设置运费与包邮门槛
设置虚拟商品发货逐个虚拟商品设置自动发货模板
设置欲蓝财务魔方全局默认服务器、账号管理
设置易支付配置商户 ID / 密钥 / 网关
设置账号与设置改密、当前账号信息
系统操作日志仅店主可见

菜单里「站点设置」与「账号与设置」是两个不同页面：前者管前台文案，后者管你自己的登录账号。

四、典型上手顺序 ​

text
① 易支付配置（填商户 ID / 密钥 / 网关）→ 让在线支付可用
      ↓
② 分类管理 → 建几个分类
      ↓
③ 商品管理 → 添加商品，选类型、填价格库存
      ↓
④ 发货配置 → 虚拟商品填模板 / 欲蓝商品填服务器与限购
      ↓
⑤ 站点设置 + 运费设置 → 改文案、设运费
      ↓
⑥ 前台下单测试 → 订单管理里确认支付与发货

五、几个通用约定 ​

  • 所有写操作成功后会重新拉取数据，不做乐观更新，列表里的状态就是数据库真实状态。
  • 口令类字段只写不读：商户密钥、欲蓝服务器口令在页面上只显示「已配置」徽标，留空表示不修改，填 __CLEAR__ 表示清除。API 响应里根本不包含这些值。
  • 保存后立即生效，不需要重启服务、不需要改 config/.env；数据库里留空的项才会回退到 .env。
  • 改完前端资源若界面没变化，Ctrl+F5 强刷一次。

常见问题速查 ​

现象处理
点什么都提示「加载失败，服务暂时不可用」没跑 php bin/migrate.php，见安装与升级
保存商品报「服务暂时不可用，请稍候再试」旧库外键子表损坏，同上，迁移脚本会自动修复
登录后立刻被踢回登录页检查 Cookie 的 Secure 设置与是否 HTTPS，见部署前准备
