这一页按后台真实返回的错误文案逐条对照。弹窗只显示一句话时，用 F12 → Network 看响应体里的 code 能精确定位。

登录与权限 ​

文案含义 / 处理
请先登录后台（401）会话失效或未登录，重新登录。会话 Cookie 是 HttpOnly + SameSite + Secure，服务端只存 token 的 SHA-256
该操作仅限店主账号（403）当前账号不是 owner 角色。敏感操作需要店主，见 后台总览

该账号登录尝试过于频繁，请稍后再试 / 注册过于频繁 / 请求过于频繁触发了频率限制，稍等再试

「请求来源不合法」403（CSRF） ​

原因：所有写操作（POST / PUT / DELETE）强制校验同源。没有 Origin（或 Referer）、或来源与站点 Host 不一致，一律拒绝。这是防跨站表单提交的正常行为，不是 bug。

常见触发场景：

  • 用 curl / Postman / 脚本调后台接口，没带头 → 加 -H "Origin: https://你的域名"
  • 反向代理把客户端的 X-Forwarded-Host 透传给了 PHP，导致同源判定被干扰 → 用 $host 而非客户端可控头
  • 前后端域名不一致（例如后台挂在另一个域）→ 统一到同一域名

支付 ​

文案处理
网关地址无效（必须是 https 地址）网关必须 https；明文 HTTP 一律拒绝，凭据也不允许塞进 URL
跳到易支付官网首页而不是收银台网关地址要填到 /submit.php，如 https://pay.xxx.com/submit.php。只填域名会打开官网首页
订单金额异常 / 订单金额异常，无法支付订单金额与网关侧不一致，重新下单
发起支付时已超时 / 免费订单发起支付时已超时支付请求超时，重试

支付成功但订单没变已付款，按这个顺序查：

  1. 异步通知（notify_url）是否可达、是否被防火墙 / CDN 拦了；回调是 GET，成功必须返回纯文本 success
  2. 验签是否通过：hash_equals 常量时间比较，签名算法取自服务端配置（不可被参数降级）
  3. 回调的状态 / 通道 / 金额是否与订单完全相等，任一不符就拒绝
  4. 是否重复通知：回调做了幂等，重复到达不会重复入账

这一套保证支付结果无法被伪造。配置字段见 支付配置。

魔方财务 / 魔方云 / 工单（v1.4） ​

现象处理
上游「测试连接」失败核对接口地址、账号、API 密钥、HTTPS；确认上游服务可达
同步产品为空检查上游接口返回格式；必要时手动录入产品
支付后未开通检查上游余额、产品上架状态、接口错误；失败会整单回滚
后台看不到已配的密钥「只写不读」：只显示「已配置」徽标；留空 = 不修改，填 __CLEAR__ = 清除
商品没按预期开通确认商品「发货配置」已绑定上游 + 上游产品并保存。见 商品管理
用户看不到某台云主机 / 工单归属隔离：只能看自己的，跨用户访问返回 404 属正常
想不接真实上游先演示站点设置开启 mock 模式（upstream_mock=1），返回模拟数据

详见 魔方财务使用教程、魔方云、工单系统。
