# 欲蓝财务 · 文档教程

欲蓝财务商城的官方文档站点（GitHub Pages）。

- 在线地址：https://yulancloud.github.io/doc
- 主仓库：https://github.com/yulancloud/yulancloud
- Windows APP：https://github.com/yulancloud/yulancloudRubik-Windows

## 本地预览

```bash
cd docs-site
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 页面

- `index.html` 首页
- `deploy.html` 部署教程（运行目录 / Nginx 伪静态 / PHP 解析 / 迁移）
- `yulan.html` 欲蓝财务魔方配置
- `windows-app.html` Windows APP 使用
- `faq.html` 常见问题
