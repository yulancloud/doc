欲蓝财务魔方

欲蓝财务魔方 ​

「欲蓝财务魔方」是商城中的一种产品类型。购买后，系统通过 Windows APP 在目标服务器上自动创建账号并交付连接信息。

一、商品类型 ​

添加 / 编辑商品时，类型下拉框提供三种选择：

类型说明
实体商品实物发货，填写物流信息
虚拟商品卡密 / 网盘链接等虚拟交付
欲蓝财务魔方下单后由 Windows APP 自动建号并交付服务器连接信息

二、商品级服务器配置 ​

每个欲蓝商品都可以单独配置自己的服务器，不再共用全局一份。在商品编辑页的「欲蓝财务魔方」面板填写：

字段说明
服务器 IP该商品对应服务器的 IP（留空则回退全局默认）
端口RDP / 服务端口
服务器账号建号时使用的管理员账号前缀
服务器口令仅写不读，响应中不会回显；填 __CLEAR__ 可清除
连接地址优先取商品级 RDP 主机名，其次商品级 IP，最后全局

提示

商品级字段非空时覆盖全局配置；全部留空则使用「全局默认」服务器设置。

三、全局默认服务器 ​

在后台「全局欲蓝设置」中配置默认服务器（IP / 端口 / 账号 / 口令 / 连接地址），作为未单独配置商品的兜底。面板标题已标注为「全局默认」以避免混淆。

四、交付流程 ​

  1. 用户下单欲蓝商品并完成支付（含 ¥0 免费直付）。
  2. 系统调用 Windows APP 的 /api/v1/create-user（Bearer 鉴权），在目标服务器建号。
  3. 建号失败则整单回滚，不会留下半成品账号。
  4. 交付页展示连接地址、账号（不含口令），口令仅服务器侧持有。
