欲蓝财务 ​

一套 PHP + SQLite 的轻量商城系统。单文件数据库，不需要 MySQL。已内置魔方云（KVM 云主机）、魔方财务（对接上游）、工单系统等商品和功能，支付完成后自动在上游开通并把连接信息交付给用户。

这个站收录部署、后台使用、功能配置、二次开发和故障排查的文档。侧边栏按场景分好了类，也可从下面的目录进入。

  • Nginx 部署 —— 需要手动填伪静态
  • Apache 部署 —— 用自带的 .htaccess，免配置
  • PHP 内置服务器 —— 本地测试用
