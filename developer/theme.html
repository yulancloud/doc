v1 插件主题教程（手动改 CSS） ​

这是旧版（v1）方式

v1.2 起，后台可直接上传主题 zip，不用手改 CSS、不用 bump 版本号、升级也不会丢，见 v2 插件主题教程（后台上传）。 本篇是早期版本的做法：手动改 public/assets/style.css 里的 CSS 变量。它仍然可用（旧版本插件主题教程），适合需要深度定制或维护老站的场景。

这套系统的视觉主题全部由 CSS 变量驱动：换主色、改圆角、调字重、配亮/暗两套配色，都只要改一个文件，不用动 PHP、不用重新打包、不用重启服务。

先找准文件

主题变量在 public/assets/style.css，前台、后台、用户中心共用同一套。PHP 侧能自定义的是文案默认值与业务参数，见 PHP 配置与文案默认值——在 src/ 里找 --accent 是找不到的。

一句话记住：改颜色去 style.css，改默认文案去 SettingsService.php，改业务参数去 config/.env。

一、变量在哪 ​

style.css 是压缩过的单行文件，变量集中在文件开头两个选择器里：

css
:root              { /* 亮色主题（默认） */ }
[data-theme=dark]  { /* 暗色主题 */ }

所有页面都写成 <html lang="zh-CN" data-theme="light">，前台与后台顶栏那个圆形按钮（[data-theme-toggle]）负责切换这个属性。用编辑器的「格式化 CSS」或搜索 :root{ 就能定位到变量块。

二、变量清单 ​

分组变量作用
文字--ink-1 ~ --ink-4主标题 → 正文 → 次要说明 → 占位/弱化
背景表面--surface-0 ~ --surface-4页面底 → 卡片 → 纯白 → 分区 → 按下态
描边--hair / --hair-2 / --hair-3分隔线的三级强度（半透明，亮暗各一套）
强调色--accent / --accent-soft / --accent-ink主色 / 主色浅底 / 压在浅底上的文字
点缀--warm暖色点缀（标签、价格）
字重--w-body / --w-med / --w-semi / --w-strong亮色 400/500/600/700，暗色整体降一档 350/440/540/620
圆角--r-xs ~ --r-xl8 / 12 / 16 / 22 / 30px
阴影--sh-1 ~ --sh-3三级投影
布局--gutter / --max / --head-h页面留白 / 最大宽度 1260px / 顶栏高度
动效--ease / --ease-soft / --ease-pop三条缓动曲线

默认主色是亮色 #0b52d8、暗色 #6e9bf5；亮色页底 #f5f6f8、暗色页底 #11141a。

三、换品牌主色（最常用） ​

亮、暗两套都要改，一共 6 个值。例如把默认蓝换成墨绿：

css
/* :root —— 亮色 */
--accent:#1f6f4f;
--accent-soft:#e6f2ec;
--accent-ink:#17563c;

/* [data-theme=dark] —— 暗色 */
--accent:#7ec6a2;
--accent-soft:#152b22;
--accent-ink:#a9dcc0;

三个变量要配套：

  • --accent 是按钮、链接、选中态的主色
  • --accent-soft 是主色的浅底（徽章、选中背景）：亮色要够浅、暗色要够深
  • --accent-ink 是压在 --accent-soft 上的文字色，必须和浅底有足够对比

只改一个变量会出现什么

只改 --accent 不改另外两个，浅底还是蓝色系、文字还是深蓝，切到暗色更会露出旧配色。三个一起改，且亮暗两套都改，才算换干净。

前台 /、/admin/、/console/ 都引用 var(--accent)，所以一处改完全站生效——但三个目录的 HTML 都带 ?v= 版本号，见第六节。

另外 public/assets/app.js 的 applyTheme() 会把 <meta name="theme-color"> 设成 #f5f6f8 / #11141a（移动端浏览器地址栏颜色）。换主色时顺手把这两个值改成新的页底色，手机上才不会割裂。

四、亮 / 暗两套必须成对改 ​

[data-theme=dark] 只覆盖部分变量：文字、背景、描边、强调色、字重、阴影；圆角、布局、动效沿用 :root。所以：

想改改动范围
圆角、间距、最大宽度、动效只改 :root 一处
任何颜色、字重、阴影:root 和 [data-theme=dark] 两处都要改

五、主题切换是怎么工作的 ​

环节实现
状态存储localStorage 的 shiwu-theme，值为 light / dark
首次访问没有存档时跟随系统 prefers-color-scheme: dark
切换动作app.js 的 initTheme() 给 <html> 写 data-theme，并加 weight-shift 类做 520ms 字重过渡
作用范围前台、后台、用户中心共用同一个 key，整域一致；前台切到暗色，后台也是暗色
首屏HTML 写死 data-theme="light"，由 JS 启动时按存档覆盖，因此有一瞬间闪白；介意的话可在 <head> 内联一段读取脚本

六、改完必须 bump 版本号 ​

所有 HTML 都引用 style.css?v=20261116e、app.js?v=20261116e。改了 CSS 却没改 ?v=，浏览器、CDN、Cloudflare 会继续用旧缓存，表现就是「我明明改了，页面没变化」。

bash
# 项目根目录执行：全站 HTML 的版本号一起换
find public -name '*.html' -print0 | xargs -0 sed -i 's/v=20261116e/v=你的新版本号/g'

然后 Ctrl+F5 强刷（或开无痕窗口）。系统对 JS/CSS 用协商缓存，正常改动会自动取新版，但升级 / 改主题后强刷一次最稳。详见 常见问题 的 Q20。

七、改之前 / 改之后 ​

  1. 备份 public/assets/style.css，改坏了一键回滚。
  2. 升级会覆盖：从 Release 整目录覆盖时 style.css 和各 HTML 都会还原成官方版本。把定制整理成一份补丁或单独记录，每次升级后重新套用，见 版本更新。
  3. 别动 config/ 目录：升级时整个 config/ 都要保留，删了安装向导会重新出现，见 安装与升级 第四节。
  4. 不要把密钥写进 CSS / JS：前端文件任何人都能下载，商户密钥、服务器口令只能放后端。

排障 ​

现象原因
改了完全没变化没 bump ?v= / CDN 缓存 / 没 Ctrl+F5
亮色正常，切到暗色还是旧色只改了 :root，漏了 [data-theme=dark]
按钮文字看不清、徽章发蓝--accent-soft / --accent-ink 没配套改
前台变了，后台没变后台 HTML 也有 ?v=，要一起 bump
升级后定制全没了被 Release 覆盖，见第二节「升级会覆盖」
