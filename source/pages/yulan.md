# 欲蓝财务魔方

「欲蓝财务魔方」是商城中的一种**产品类型**。购买后，系统通过 Windows APP 在目标服务器上自动创建账号并交付连接信息。

## 一、商品类型

添加 / 编辑商品时，类型下拉框提供三种选择：

| 类型 | 说明 |
| --- | --- |
| 实体商品 | 实物发货，填写物流信息 |
| 虚拟商品 | 卡密 / 网盘链接等虚拟交付 |
| 欲蓝财务魔方 | 下单后由 Windows APP 自动建号并交付服务器连接信息 |

## 二、商品级服务器配置

每个欲蓝商品都可以**单独配置自己的服务器**，不再共用全局一份。在商品编辑页的「欲蓝财务魔方」面板填写：

| 字段 | 说明 |
| --- | --- |
| 服务器 IP | 该商品对应服务器的 IP（留空则回退全局默认） |
| 端口 | RDP / 服务端口 |
| 服务器账号 | 建号时使用的管理员账号前缀 |
| 服务器口令 | 仅写不读，响应中不会回显；填 `__CLEAR__` 可清除 |
| 连接地址 | 优先取商品级 RDP 主机名，其次商品级 IP，最后全局 |

::: tip
商品级字段非空时覆盖全局配置；全部留空则使用「全局默认」服务器设置。
:::

## 二·补、财务魔方多 API（v1.3 新增）

如果有多台 Windows 服务器，推荐用「财务魔方 API」统一管理，而不是在每件商品里重复填 IP 和口令。

1. 后台左侧「**财务魔方 API**」→ 新增，给每条连接起一个可辨识的名称（如「电信机房-A」），填各自的服务器 IP / 端口 / 口令 / 交付地址，可随时启用或停用。
2. 商品「发货配置 → 使用哪个 API」下拉里选中它。
3. 建号、改密、交付连接地址都会走这条 API。

**优先级**：商品绑定的 API > 商品级服务器配置 > 全局默认。也就是说，只要商品选了 API，下面两级就不生效了。

::: warning
- 连接口令只写不读，后台不会回显；编辑时留空表示不修改。
- 删除仍被商品使用的 API 会被拦截；确认要删可选「强制删除」，系统会自动把这些商品改回「不使用 API」。
- 「服务器 IP」务必填**运行 Windows APP 那台机器的 IP**（默认 8321 端口），不是网站域名。若填成网站域名，建号会报「接口不存在」，v1.3 起会给出明确诊断提示。
:::

## 三、全局默认服务器

在后台「全局欲蓝设置」中配置默认服务器（IP / 端口 / 账号 / 口令 / 连接地址），作为未单独配置商品的兜底。面板标题已标注为「全局默认」以避免混淆。

## 四、交付流程

1. 用户下单欲蓝商品并完成支付（含 ¥0 免费直付）。
2. 系统调用 Windows APP 的 `/api/v1/create-user`（Bearer 鉴权），在目标服务器建号。
3. 建号失败则整单回滚，不会留下半成品账号。
4. 交付页展示连接地址、账号（**不含口令**），口令仅服务器侧持有。
