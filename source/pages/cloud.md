# 魔方云 · KVM 云服务器

魔方云是 v1.4.0 新增的商品类型，参考智简魔方云等 KVM 云主机管理系统的 RESTful API 模式：用户购买云主机商品并支付后，系统自动在上游创建云主机实例，交付「连接地址 / 系统 / 配置 / 一次性密码」，用户可在用户中心自助管理。

::: tip 和魔方财务的区别
- 魔方云：卖的是 KVM 云服务器，开通后是一台可以开机/关机/重启/重装/重置密码的云主机，走 `cloud` 类型上游。
- 魔方财务：对接上游财务系统代理产品，走 `finance` 类型上游。

两者共用同一套「上游」模型，只是类型和接口不同。详见[魔方财务（对接上游）](/yulan)。
:::

## 一、整体链路

| 角色 | 在哪配置 | 干什么 |
| --- | --- | --- |
| 商城网站 | 你的 PHP + SQLite 站点 | 收单、维护云主机商品与上游、展示实例与交付信息 |
| 上游（cloud 类型） | 后台「魔方财务 · 上游管理」里类型选 `cloud` | 记录魔方云 KVM 接口地址、账号、API 密钥、财务标识 |
| 云主机实例 | 自动创建，后台 / 用户中心可查看 | 已开通的 VPS，可开机、关机、重启、重置密码 |

付款后的调用链路：

> 用户付款 → 商城按商品绑定的 cloud 上游调用 `/api/v1/vm/create` → 上游创建云主机并返回 IP / 账号 / 密码 / 配置 → 商城写入实例表与交付内容 → 用户中心可自助管理。

## 二、第一步：添加魔方云上游

左侧「魔方财务 · 上游管理 → 新增」，类型选 `cloud`（魔方云 KVM），按实际接口填写：

| 字段 | 说明 |
| --- | --- |
| 名称 | 如「魔方云-A机房」 |
| 类型 | 选 cloud（魔方云 KVM） |
| 接口地址 | 魔方云 KVM 面板的 API 地址（IP 或域名，可含 `https://`） |
| 账号 / API 密钥 | 上游提供的接口凭证，密钥只写不读 |
| 财务标识 | 上游要求的 financial_id（如接口需要） |
| HTTPS | 接口是否走 https |

保存后可点「测试连接」验证。接口约定见下方「对接接口约定」。

## 三、第二步：同步云主机产品

进入该上游的「产品」，点「同步产品」拉取云主机套餐（如 1核1G / 2核4G 等），维护名称、规格、成本价与上架状态；也可手动录入。

## 四、第三步：商品类型选「魔方云」

1. 在「商品管理 → 新增/编辑」里，类型选「魔方云（KVM 云服务器）」。
2. 在「发货配置」里选中刚才的 cloud 上游 + 对应产品。
3. 设置销售价（相对成本价加价）。

支付成功后，系统自动在上游创建云主机并交付。

## 五、用户中心「我的云主机」

用户中心新增「我的云主机」标签，用户可看到自己已开通的实例，包括：

- IP 地址、操作系统、CPU / 内存 / 硬盘 / 带宽、地域、状态
- 自助操作：开机 / 关机 / 重启 / 重置密码
- 关联订单、开通时间

::: warning 归属隔离
用户只能看到并操作自己名下的云主机；跨用户访问会被拒绝（404）。平台不长期保存明文密码，密码仅在开通时一次性写入交付内容。
:::

## 六、后台「魔方云 · 云主机」

后台左侧「魔方云 · 云主机」可查看全部实例（支持筛选），并对任一实例执行开机 / 关机 / 重启 / 重置密码。操作后本地状态会同步更新。

## 七、对接接口约定（给技术/上游对接人员）

上游需提供以下 RESTful 接口（具体路径以你的上游为准，本系统按约定调用）：

| 用途 | 方法 / 路径 | 说明 |
| --- | --- | --- |
| 拉取产品 | `GET /api/v1/products` | 返回产品数组，兼容 `{data:[…]}` / `{products:[…]}` / 裸数组 |
| 创建云主机 | `POST /api/v1/vm/create` | 传入产品与订单信息，返回实例信息（IP / 账号 / 密码 / 配置 / 外部 ID） |
| 实例操作 | 对应开机 / 关机 / 重启 / 重置密码接口 | 传入上游实例 ID 与操作类型 |

鉴权方式与 `finance` 上游一致（账号 + API 密钥）。mock 模式（站点设置 `upstream_mock=1`）下不联网，返回模拟实例，便于测试。
