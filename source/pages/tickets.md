# 工单系统

工单系统是 v1.4.0 新增的客服支持功能：用户在用户中心提交问题工单、追加回复、关闭工单；客服在后台受理、回复、切换状态。适合处理账号、支付、产品、技术等各类售后问题。

## 一、用户侧（用户中心「工单」）

用户中心新增「工单」标签，可：

- 提交工单：填写标题、分类、优先级、描述，可关联订单。
- 查看详情：看到工单状态、全部对话历史。
- 追加回复：与客服来回沟通。
- 关闭工单：问题解决后自行关闭。

| 字段 | 说明 |
| --- | --- |
| 标题 | 简要描述问题 |
| 分类 | 账号 / 支付 / 产品 / 技术 / 其他 |
| 优先级 | 低 / 普通 / 高 |
| 关联订单 | 可选，填上便于客服定位 |
| 描述 | 问题详情（去控制字符，最多 4000 字） |

提交后系统生成工单号（如 `TK20261120XXXX`），便于沟通时引用。

::: warning 归属隔离
用户只能查看和回复自己提交的工单，访问他人工单会返回 404。
:::

## 二、后台「工单管理」

左侧「工单管理」页面：

- 列表：按状态等条件筛选，查看全部工单。
- 详情：查看工单信息与完整对话历史。
- 回复客户：以客服身份追加回复。
- 切换状态：待处理 / 处理中 / 已回复 / 已关闭。

## 三、状态流转

工单有四种状态：

| 状态 | 含义 |
| --- | --- |
| `open` 待处理 | 用户刚提交，客服尚未受理 |
| `processing` 处理中 | 客服已受理，正在处理 |
| `replied` 已回复 | 客服已回复，等待用户反馈 |
| `closed` 已关闭 | 问题结束，用户或客服关闭 |

用户与客服的每次回复都会追加到对话历史，双方都能看到完整沟通记录。
