# 魔方财务使用教程（从零到交付）

这是一篇**从头到尾的实操教程**：照着做一遍，就能把「添加上游 → 同步产品 → 商品绑定加价 → 用户下单支付 → 上游自动开通交付」整条链路跑通。本篇专注于**怎么一步步配起来**，概念与字段说明见 [魔方财务（对接上游）](/yulan)。

::: warning v1.4 重要变化
自 v1.4.0 起，魔方财务改为**对接上游财务系统**，早期通过本地 Windows 建号端开通的方式已移除。本教程是 v1.4 的上游对接流程。从旧版升级后未绑定上游的老商品仍按原行为兼容运行，但新配置请统一走本教程。
:::

## 零、先弄懂这套东西由哪几块组成

魔方财务对接是**三块配合**工作的，先认清楚后面排查不迷路：

| 角色 | 装在哪 | 干什么 |
| --- | --- | --- |
| **商城网站** | 你的 PHP + SQLite 站点（本系统） | 收单、维护上游与产品、加价销售、给用户展示交付信息 |
| **上游（finance）** | 商城后台「魔方财务 · 上游管理」 | 记录「去哪家上游进货」的接口地址、账号、API 密钥 |
| **上游产品** | 上游管理里的产品列表 | 从上游同步的产品目录，供商城商品绑定设置销售价 |

数据流一句话：

> 用户付款 → 商城找到商品绑定的**上游 + 上游产品** → 调用上游接口创建订单并开通 → 上游返回连接信息 → 商城写入交付内容，用户查看。

## 一、第一步：在后台添加一条上游

登录商城后台，左侧点 **魔方财务 · 上游管理 → 新增**，按下面填：

| 字段 | 填什么 |
| --- | --- |
| 名称 | 起个好认的名字，如「上游A-魔方财务」，仅后台辨识用 |
| 类型 | 选 **finance（对接上游财务系统）** |
| 接口地址 | 上游提供的 API 地址（IP 或域名，可含 `https://`） |
| 账号 | 上游提供的接口账号 |
| API 密钥 | 上游提供的密钥。**只写不读**，保存后不回显 |
| 财务标识 | 如上游接口需要，填其 financial_id |
| 账号类型 | 代理商 `agent` / 普通 |
| HTTPS | 上游接口走 https 就打开 |
| 状态 | 启用 / 停用 |

填完点「测试连接」，确认接口地址、账号、密钥、HTTPS 都对；通过后保存。

::: tip 密钥只写不读
API 密钥保存后不会回显。再次编辑时留空 = 不修改；确认要清空填 `__CLEAR__`。忘记时重新填一遍覆盖即可。
:::

## 二、第二步：同步上游产品

1. 在上游列表点该上游的「产品」，进入产品目录。
2. 点「同步产品」，系统会请求上游拉取产品列表（兼容 `data` / `products` / 裸数组等返回格式）。
3. 同步回来后，逐项维护**名称、规格描述、上游成本价、上架状态**；也可手动新增 / 编辑。

同步回来的产品，是下一步「商品绑定」的备选项。**成本价来自上游，销售价在你自己的商城商品上设置**，两者之差就是利润。

::: tip 想先演示、不接真实上游？
在站点设置开启 **mock 模式**（`upstream_mock=1`），同步产品、创建云主机都会返回模拟数据，不联网即可把整条流程走一遍，适合测试和试用。
:::

## 三、第三步：把商品绑定到上游产品

建好上游、同步产品后，告诉系统**哪个商品卖哪个上游产品**：

1. 左侧 **商品管理 → 编辑** 目标商品，类型选「魔方财务（对接上游）」或「魔方云（KVM 云服务器）」。
2. 在 **发货配置** 里找到 **上游** 下拉框，选中对应上游。
3. 再在 **上游产品** 下拉框选中该产品（下拉随上游联动加载）。
4. 保存。

支付后，系统按这个绑定关系自动在上游下单开通。

::: warning 新建商品要分两步
刚创建时还没有商品 ID，发货配置要**先保存商品，再回来设**。保存后在列表点「发货配置」即可。这是[商品管理](/admin/products)里就有的通用规则。
:::

## 四、加价销售定价

- **成本价**：从上游同步 / 维护在上游产品上，是你进货的价钱。
- **销售价**：在商城商品的售价上设置，是用户支付的价钱。
- **你的利润** = 销售价 − 成本价。

按需给不同商品设不同销售价即可实现分层定价。

## 五、用户下单后发生什么

1. 用户下单并完成支付（含 ¥0 免费直付）。
2. 系统按商品绑定的上游与产品，调用上游接口创建订单并开通。
3. 上游返回的连接信息写入**交付内容**，用户在订单 / 交付页查看（连接地址、账号；密码等敏感信息按上游返回与平台策略处理）。
4. 开通失败会走事务回滚，不会留下「钱付了却没开通」的半成品订单。

若买的是云主机商品，用户还能在 **用户中心 → 我的云主机** 自助开机 / 关机 / 重启 / 重置密码，详见[魔方云](/cloud)。

## 六、常见故障速查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 测试连接失败 | 接口地址、账号、密钥、HTTPS 有误，或上游不可达 | 逐项核对上游配置；确认上游服务在线、地址可达 |
| 同步产品为空 | 上游返回格式不匹配或无产品 | 检查上游接口返回；必要时手动录入产品 |
| 商品不选上游产品 | 上游未启用 / 未保存发货配置 | 确认上游状态为「启用」，商品发货配置已保存 |
| 开通失败 | 上游余额不足、产品下架、接口报错 | 看接口错误信息，检查上游账户与产品状态；失败会整单回滚 |
| 看不到新菜单 | 升级后浏览器缓存 | `Ctrl+F5` 强刷后台 |

更完整的排查见 [后台与业务故障](/troubleshoot/backend) 与 [故障排查总览](/troubleshoot)。

## 七、升级与迁移

- 从旧版升到 v1.4：解压覆盖站点时**保留 `config/` 与 `data/`**，再执行 `php bin/migrate.php`（幂等，会新建 `upstreams / upstream_products / cloud_vms / tickets / ticket_replies` 五张表，并给 `products` 放开 cloud 类型、补 `upstream_id/upstream_product_id` 列，不丢历史数据）。
- 也可用后台「在线更新」一键升级，会自动备份、覆盖程序文件并跑迁移，**保留你的主页设计、设置、商品和订单**。
- 升级后 `GET /api/health` 应返回 `version=1.5.0`、`build=20261122a`；`Ctrl+F5` 强刷后台即可看到「魔方财务 · 上游管理」「魔方云 · 云主机」「工单管理」新菜单。详见[安装与升级](/deploy/install)与[版本更新](/changelog)。
