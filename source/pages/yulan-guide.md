# 魔方财务使用教程（从零到交付）

这是一篇**从头到尾的实操教程**：照着做一遍，就能把「用户下单 → 自动在服务器上建号 → 用户拿到连接信息并自己改号改密」整条链路跑通。

如果你只想了解「欲蓝财务魔方」是什么、字段什么意思，看概念页 [欲蓝财务魔方](/yulan)；本篇专注于**怎么一步步配起来**。

## 零、先弄懂这套东西由哪几块组成

魔方财务不是装在一个地方就完事，它是**三块配合**工作的。先认清楚，后面排查不迷路：

| 角色 | 装在哪 | 干什么 |
| --- | --- | --- |
| **商城网站** | 你的 PHP + SQLite 站点（本系统） | 收单、管理商品与 API、给用户展示交付信息与改号入口 |
| **财务魔方 API**（后台里的一条配置） | 商城后台「财务魔方 API」菜单 | 记录「去哪台服务器建号、用什么口令」，可建多条、起名字 |
| **Windows APP**（建号端） | 你自己的一台 Windows 服务器 | 真正执行建号 / 改密，监听 `8321` 端口 |

数据流一句话：

> 用户付款 → 商城找到商品绑定的那条 **API** → 按 API 里的 IP / 端口 / 口令，去请求 **Windows APP** 的 `/api/v1/create-user` → APP 在服务器上建号 → 商城把「连接地址 + 账号」交给用户。

::: warning 最容易踩的坑（先记住）
后台「服务器 IP」要填的是**运行 Windows APP 那台 Windows 机器的 IP**，默认端口 `8321`。**不是你的网站域名，也不是网站服务器的 IP**。填成网站域名，请求会打到网站而不是 APP，报「接口不存在 / APP 返回异常」。
:::

## 一、第一步：在 Windows 服务器上装好并启动 APP

建号端是官方打包的单文件 exe，**自带 Python 运行环境，免安装**。

1. 到 [yulancloudRubik-Windows 仓库 Release](https://github.com/yulancloud/yulancloudRubik-Windows/releases/tag/v1.3.0) 下载 `yulan_cube_app.exe`（约 7.4 MB），放到一个专门的文件夹。
2. 同目录放一份配置文件 `yulan_cube_config.json`（首次运行不存在会自动生成）。最小可用配置：

   ```json
   {
     "listen_host": "127.0.0.1",
     "listen_port": 8321,
     "token": "在这里填一个强口令，例如 Yulan@2026#Cube",
     "default_role": "admin",
     "admin_group_name": "yulan-admins",
     "rdp_group_name": "yulan-rdp",
     "server_ip": "10.0.0.5"
   }
   ```

3. **双击 exe** 运行，Windows 弹出 UAC 提权提示时点「是」。APP 只允许管理员账号运行，日志仅管理员组可读。
4. 自检：浏览器访问 `http://服务器IP:8321/api/v1/health`，返回 `version: 1.3.0` 就说明 APP 正常在跑。

::: tip 这里有两个关键值，等下后台要用
- **APP 的 IP + 端口**：`服务器IP:8321`（给后台「服务器 IP / APP 端口」用）。
- **APP 的 token**：配置文件里 `token` 的值（给后台「连接口令」用）。**两边必须一模一样**，否则建号会被拒绝，日志提示「Token 未配置 / 无效」。
:::

::: warning 安全边界
APP 用明文 HTTP 通信，`listen_host` 保持 `127.0.0.1` 或仅内网可达，**不要把 8321 端口直接暴露到公网**。需要跨机访问时，用防火墙限定来源 IP。详见 [Windows APP](/windows-app)。
:::

## 二、第二步：在后台建一条「财务魔方 API」

登录商城后台，左侧点 **财务魔方 API → + 新增 API**，按下面填：

| 字段 | 填什么 |
| --- | --- |
| API 名称 | 起个好认的名字，如「电信机房-A」，仅后台辨识用 |
| 服务器 IP / 域名 | **第一步那台 Windows 机器的 IP**（如 `203.0.113.10`），不是网站域名 |
| APP 端口 | APP 的 `listen_port`，默认 `8321` |
| 连接账号（可选） | 一般**留空即可**，建号用的是 APP 配置里的管理员组，这里不影响 |
| 交付用连接地址 | 展示给用户去远程连接的地址；留空则自动用上面的服务器 IP |
| 状态 | 启用 / 停用。停用后绑定它的商品会回退到商品级 / 全局配置 |
| 连接口令 | **填第一步 APP 配置里的 `token`**，至少 6 位。只写不读，保存后不回显 |

保存后列表里会看到这条 API，「口令」列显示「已配置」即成功。

::: tip 口令只写不读
出于安全，连接口令保存后**不会回显**。再次编辑时留空 = 不修改；确认要清空就填 `__CLEAR__`。忘记口令时，直接重新填一遍 APP 的 token 覆盖即可。
:::

可以照这个方法建多条，比如「电信机房-A」「联通机房-B」，分别指向不同服务器。

## 三、第三步：把商品绑定到这条 API

建好 API 只是「有一条连接」，还要告诉系统**哪个商品用哪条**。

1. 左侧 **商品管理 → 编辑** 目标商品（类型选「欲蓝财务魔方」）。
2. 在 **发货配置** 里找到 **「使用哪个 API」** 下拉框，选中刚建的那条（如「电信机房-A」）。
3. 保存。之后再点开，下拉里选中的就是它。

::: warning 新建商品要分两步
刚创建时还没有商品 ID，发货配置要**先保存商品，再回来设**。保存后在列表点「发货配置」即可。这是[商品管理](/admin/products)里就有的通用规则。
:::

绑定后，这件商品的**建号、改密、交付连接地址**都会走这条 API。多台服务器就靠这个下拉分流，互不影响。

**删除 API 注意**：如果某条 API 还被商品使用，直接删会被拦下并提示「仍被 N 个商品使用」。要么先去商品里改绑 / 清空，要么确认后「强制删除」——系统会自动把那些商品改回「不使用 API」。

## 四、配置优先级（记住这一条就够）

建号参数可能来自三个地方，系统按下面顺序取，**命中即停**：

```
商品绑定的 API  >  商品级服务器配置  >  全局默认服务器
```

- 商品在「使用哪个 API」里选了 API → 完整用这条 API 的 IP / 端口 / 口令，**下面两级都不生效**。
- 没选 API，但商品「发货配置」里填了自己的服务器 IP / 口令 → 用商品级配置。
- 两级都没填 → 用后台「全局欲蓝设置」的默认服务器兜底。

::: tip
所以「财务魔方 API」不是必须用的。只有一台服务器、图省事，直接在「全局欲蓝设置」里配一次也能跑；多服务器、要分流时才需要建多条 API。
:::

## 五、用户下单后拿到什么、怎么改号改密

### 用户侧（前台）

1. 用户在商城下单欲蓝商品并完成支付（含 ¥0 免费直付）。
2. 系统按上面的优先级找到 API，调用 Windows APP 建号。
3. 建号成功 → 交付页展示**连接地址 + 账号**（不含口令）；失败则整单回滚，不留半成品账号。
4. 用户进入 **用户中心 → 我的欲蓝财务魔方账号**，能看到自己已创建的账号；点「详情」可以：
   - **改登录用户名**：填新用户名，APP 以管理员权限改名（无需旧密码）。
   - **改密码**：填新密码（至少 8 位、含字母和数字），APP 强制重置。
   - 两项至少填一项，留空表示不改。口令不落库、不下发到前端。

改完后，用户用**新用户名 / 新密码**登录远程桌面，旧的立即失效。

### 店主侧（后台）

后台左侧 **欲蓝财务魔方** 页面可以：查看全局默认配置、**管理已创建的 Windows 账号**（停用 / 恢复某个账号）。详见[站点设置与其他](/admin/settings)。

## 六、常见故障速查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 「欲蓝账号创建失败，APP 返回异常」 | 后台「服务器 IP」填成了网站域名，请求打到网站而非 APP | 改成运行 APP 的 Windows 机器 IP，端口 `8321`。v1.3 起会给出明确诊断 |
| 日志提示「Token 未配置 / 无效」 | 后台「连接口令」和 APP 配置的 `token` 不一致，或 token 还是中文占位符 | 两边填同一个强口令并重启 APP |
| 连不上 / 超时 | APP 没启动、端口不对、防火墙没放行 | 访问 `/api/v1/health` 自检；确认 `listen_port` 与后台一致；防火墙放行该端口 |
| 提示「需要管理员权限」/ 闪退 | APP 不是用管理员账号跑的 | 右键以管理员身份运行，或用 `run_as_admin.bat` |
| 商品明明选了 API 却不生效 | API 被停用，或没保存发货配置 | 确认 API 状态为「启用」，商品发货配置已保存 |
| 删除 API 被拒 | 仍被商品引用 | 先改绑商品，或确认后强制删除（自动解绑） |

更完整的排查见 [Windows APP 故障](/troubleshoot/app) 与 [后台与业务故障](/troubleshoot/backend)。

## 七、升级与迁移

- 从旧版升到 v1.3：解压覆盖站点时**保留 `config/` 与 `data/`**，再执行 `php bin/migrate.php`（幂等，会自动补 `yulan_apis` 表和 `products.yulan_api_id` 列，不丢数据）。
- 也可用后台「在线更新」一键升级，会自动备份、覆盖程序文件并跑迁移，**保留你的主页设计、设置、商品和订单**。
- 升级后 `Ctrl+F5` 强刷后台，才会看到「财务魔方 API」「在线更新」新菜单。详见[安装与升级](/deploy/install)与[版本更新](/changelog)。
