# 双主题与支付方式（v1.6.0）

v1.6.0 起，前台支持「经典 / 创新」两套界面风格，并新增 5 种支付方式的配置框架。

## 一、切换界面风格

进入后台 → **站点设置** → 找到 **界面风格**：

| 选项 | 效果 |
|---|---|
| `经典（当前风格）` | 手作器物风格首页 / 商品 / 控制台（默认，老用户无感） |
| `创新（智简魔方风格）` | TDesign 蓝白风格，首页根路径自动跳转到 `/innovative/` |

保存后立即生效，无需重启。两主题资源目录完全隔离，互不污染；数据库不可用时自动回退经典主题。

### 创新主题包含什么

innovative 主题从智简魔方 v10 真实源码提取设计语言（品牌蓝 `#0052d9`、白底卡片、统计大数字），含三套页面：

- **首页** `/innovative/`：深蓝渐变 Hero + 统计卡 + 产品中心，实时读取站点文案与商品数据；
- **登录 / 注册** `/innovative/login.html`：分栏布局，支持登录 / 注册切换（邮箱验证码由 SMTP 插件提供，未装插件可直接注册）；
- **控制台** `/innovative/console.html`：左侧菜单 + 顶栏 + 卡片，接入订单、云主机、财务魔方账号、工单、余额、账号设置全部视图，全部走真实 API。

::: tip
想让顾客访问根路径直接看到创新主题，把「界面风格」设为「创新」即可；想随时切回，改回「经典」即可。
:::

## 二、双品牌共存

站点设置新增两个字段：

- **主品牌名**（`brand_primary`，默认「欲蓝财务魔方」）
- **副品牌名**（`brand_secondary`，默认「魔方财务」）

创新主题登录页左侧品牌区会同时展示这两个名字。商品类型 `yulan`（魔方财务·对接上游）与 `cloud`（魔方云 KVM）保持不变。

## 三、支付方式（5 种）

后台新增菜单 **支付方式（5 种）**，可开启渠道并填写资质。支持：

| 方式 | 依赖 | 未配置时 |
|---|---|---|
| 余额支付 | 用户余额 | 恒可用 |
| 易支付（微信 / 支付宝） | PID + KEY + 网关 | 配置后可用 |
| 微信 H5 | 易支付 wxpay + 手机端 | 后台未开启则隐藏 |
| 微信官方支付 | 商户号 + AppID + APIv3 密钥 | 回退易支付微信 |
| 支付宝支付 | 支付宝 AppID + 应用私钥 + 公钥 | 回退易支付支付宝 |
| 支付宝当面付 | 复用支付宝资质 | 回退易支付支付宝 |

::: warning
官方渠道需要企业商户资质（AppID + 密钥）。当前版本填入资质后，统一落地通道仍是易支付；未配置完整时前台自动置灰提示，用户下单会自动回退到易支付对应通道——保证不会出现「付不了款」。密钥只写不读，出于安全不回显。
:::

两处 API：

- 前台 `GET /api/payment/methods`（返回可用方式清单）
- 后台 `GET /api/admin/payment/methods`

## 四、升级要点

1. 备份 `data/shop.sqlite` 与 `config/.env`；
2. 下载 `yulan-shop-v160.zip` 覆盖站点（保留 `config/` 与 `data/`）；
3. 刷新 `GET /api/health`，确认 `version=1.6.0`、`build=20261128a`；
4. 后台选择界面风格、按需配置支付方式。

本版本无新增表、无 schema 变更，纯 KV 设置 + 静态资源，零迁移成本。
