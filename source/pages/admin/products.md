# 商品管理

入口：左侧 **商品管理**。列表支持按名称搜索、按分类 / 状态筛选、上架下架。

## 一、添加 / 编辑商品

点击「添加商品」打开抽屉表单，字段如下：

| 字段 | 说明 |
| --- | --- |
| 商品名称 | 必填，最多 80 字 |
| **商品类型** | 必填下拉框，见下节 |
| 分类 | 必填，来自左侧「分类管理」菜单，见下文第三节 |
| 售价（元） | 必填，如 `188.00`，内部按分存储 |
| 库存 | 必填，整数 |
| 颜色 / 规格 / 参数 / 保养 | 可增删的子表，用于前台展示 |
| **商品缺点 / 已知不足** | 每行一条，前台详情页「已知不足」栏逐条展示；留空整栏自动隐藏，见[第四节](#四商品缺点--已知不足v11-起) |
| 品牌故事 / 商品描述 | 多行文本 |
| 发货配置 | 见第五节 |

::: tip 新建商品要分两步
刚创建时还没有商品 ID，**发货配置需要先保存商品再回来设**。保存后在列表点「发货配置」即可。
:::

## 二、商品类型（三选一）

这是添加 / 编辑表单里的「商品类型」下拉框，决定下单后怎么交付：

| 类型 | 值 | 交付方式 |
| --- | --- | --- |
| 实体商品 | `physical` | 人工发货，需填收货地址、走运费 |
| 虚拟商品 | `virtual` | 按发货模板**自动发货**（卡密、链接等） |
| 魔方财务（对接上游） | `yulan` | 支付后在上游财务系统创建订单并开通，按上游返回的连接信息交付 |
| 魔方云（KVM 云服务器） | `cloud` | 支付后在上游创建云主机并交付，用户可自助开关机 / 重启 / 重置密码 |

::: warning
编辑已有商品时，如果不重新选择类型，会**保持原类型不变**。要改类型必须显式在下拉框里选一次。
:::

## 三、分类管理

左侧 **分类管理** 里维护「分类编号 + 分类名称」。删除分类时，若该分类下还有商品会被拒绝，需先转移或删除商品。

## 四、商品缺点 / 已知不足（v1.1 起）

添加 / 编辑商品表单里的多行文本框，**每行一条**，例如：

```text
手工拉坯，同一批次的高度会有 3–5mm 差异，属正常工艺范围。
哑光釉怕骤冷骤热，刚从冰箱取出不宜立刻冲热水。
杯口一圈的釉线会有极轻微的厚薄不均，这是手工施釉的痕迹。
```

- 前台商品详情页「已知不足」栏会逐条渲染这些文字，保存后立即生效
- **留空则整栏自动隐藏**，不会留下空面板
- 该字段存于 `products.flaws`，旧库升级后执行 `php bin/migrate.php` 自动补列
- 未跑迁移时保存商品不会报错（后端会先探测列是否存在），只是缺点内容暂时存不上

::: tip 为什么要主动写缺点
每件器物都写清已知不足，是这套模板的设计意图：把不完美提前说清楚，减少退货与预期落差。演示数据里 8 件商品都预填了三条，可在后台逐件改成自己的实际情况。
:::

## 五、发货配置

点商品行的「发货配置」，可设置：

### 1）发货类型与模板

- **虚拟商品**：填自动发货内容模板，支持占位符（例如卖卡密填卡号，卖网页填链接）。
- **实体商品**：不需要模板，人工发货。
- **魔方财务 / 魔方云**：不填模板，支付后由上游开通，交付内容由上游返回的连接信息生成；**密钥平台不存储**，只保存连接信息。

### 2）上游配置（魔方财务 / 魔方云）

商品发货配置里可绑定**上游 + 上游产品**：

| 字段 | 说明 |
| --- | --- |
| 上游 | 选中一条已启用的上游（finance 用于魔方财务，cloud 用于魔方云） |
| 上游产品 | 随所选上游联动加载，选中要销售的套餐 / 产品 |

销售价在商品自身售价上设置，与上游成本价的差额即利润。详见 [魔方财务使用教程](/yulan-guide)。

::: tip 先建上游再绑商品
上游需在「魔方财务 · 上游管理」里先添加并同步产品；新建商品要**先保存商品，再回来设发货配置**。详见 [魔方财务（对接上游）](/yulan)。
:::

## 六、上架 / 下架

列表每行有「上架 / 下架」按钮，状态为 `active`（在售）或 `hidden`（下架）。下架商品前台不再展示，历史订单不受影响。

## 七、常见报错

| 现象 | 原因 |
| --- | --- |
| 保存报「服务暂时不可用，请稍候再试」 | 旧库子表外键损坏或未跑迁移，执行 `php bin/migrate.php`，见[安装与升级](/deploy/install) |
| 发货配置打不开 / 提示「加载失败」 | 同上，新列不存在 |
| 类型下拉框不出现 | 前端资源被缓存，`Ctrl+F5` 强刷 |
| 后台填了缺点，前台详情页还是旧内容 | 未跑迁移或浏览器缓存；执行 `php bin/migrate.php` 后 `Ctrl+F5` 强刷，见[版本更新](/changelog) |
| 密钥填了看不到值 | 设计如此，只写不读，见[后台总览](/admin) |
