# 站点设置与其他

这一篇覆盖后台里剩下的日常管理菜单。注意「站点设置」和「账号与设置」是两个不同页面。

## 一、站点设置

左侧 **站点设置**：管理前台展示的站点文案（站点名、公告、页脚等）。

- 文案**保存在数据库**，保存后立即生效
- 不需要改 HTML、不需要重启服务
- 支付参数不在这里，去 [易支付配置](/admin/payment)

## 二、运费设置

左侧 **运费设置**：只管运费金额与包邮门槛，独立于站点设置。实体商品走运费，虚拟 / 欲蓝商品不涉及。

## 三、虚拟商品发货

左侧 **虚拟商品发货**：逐个虚拟商品设置各自的自动发货内容模板（卡密、链接等）。与[商品管理](/admin/products)里的「发货配置」是同一份数据的另一个入口，按商品维度配置。

## 四、欲蓝财务魔方（全局默认）

左侧 **欲蓝财务魔方**：配置全局默认服务器与令牌，并管理已创建的 Windows 账号（可停用 / 恢复）。

**每个商品可以有自己的服务器**，在商品「发货配置」里填；留空才回退这里的全局默认。详见 [欲蓝财务魔方](/yulan)。

::: warning
全局默认与商品级配置里的口令都「只写不读」，页面只显示「已配置」徽标。详见[商品管理](/admin/products)。
:::

## 五、用户管理

左侧 **用户管理**：查看注册用户、停用 / 恢复账号。

- 停用后该用户无法登录，**现有会话立即失效**
- 停用前会二次确认

## 六、评价管理

左侧 **评价管理**：审核前台商品评价。前端渲染评价文本时统一做转义，不存在存储型 XSS。

## 七、账号与设置（改密）

左侧 **账号与设置**：查看当前登录账号、修改密码。

::: warning 改密影响其他设备
改密后该账号在**其他设备上的登录会全部失效**，当前会话保留。首次登录后若仍是初始密码，系统会提示尽快修改。
:::

## 八、操作日志

左侧 **操作日志**，**仅店主（owner）可见**，店员看不到该菜单并记录后台敏感操作。排查「谁改了配置」时看这里。
