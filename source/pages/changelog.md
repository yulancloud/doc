# 版本更新

这里记录每个版本相对上一版的变化与升级要点。升级前请先备份 `data/shop.sqlite` 与 `config/.env`。

## v1.4.1（修复补丁 · 在线更新与对接上游）

> 商城系统版本。`GET /api/health` 返回 `version=1.4.1`、`build=20261121a`。这是一个纯修复补丁，不新增表、不改存量数据结构。

修复 v1.4.0 上线后反馈的两类问题：

- **后台在线更新超时**：
  - 前台把更新检查 / 执行接口的超时从默认 15 秒放宽到 180 秒，按钮增加「可能需要几分钟、请勿关闭或重复点击」提示。
  - 后端更新执行前解除 PHP 执行时间限制（`set_time_limit(0)` / `ignore_user_abort(true)`），避免写文件写到一半被 30 秒上限杀掉。
  - 「检查更新」阶段的 GitHub 请求改用短超时快速失败，两个端点不再串行各等 120 秒，解决「请求超时」。
- **对接上游核心问题**：
  - **开通时机统一**：绑定上游的 `yulan` 商品从「下单即开通」改为**支付成功后开通**，与 `cloud` 一致；未付款不再触发上游扣费 / 开资源，也不会因事务回滚留下「钱付了没账号」的半成品。
  - **账号密码免填**：上游模式下账号 / 密码由上游返回，购物车不再强制用户填写 Windows 账号密码；未绑定上游的存量商品仍保留旧流程（兼容）。
  - **协议可配置**：上游新增 `auth_mode`（bearer / basic / query / none）、`api_base_path`、产品 / 开通 / 操作路径、价格单位 `price_is_cents` 等字段，管理员可按真实魔方云 / 魔方财务 API 填写鉴权方式与路径，不再写死自造协议。
  - **安全与健壮性**：接口地址禁止内网 / 回环地址（收紧 SSRF）；兼容真实上游多种 IP / 密码字段名；修复 `financial_id` 重复赋值与交付变量覆盖隐患。

> 升级：下载 `yulan-shop-v141.zip` 覆盖站点（保留 `config/` 与 `data/`），执行 `php bin/migrate.php`（幂等，可重复跑），确认 `build=20261121a` 后 `Ctrl+F5` 强刷后台即可。

## v1.4.0（魔方云 · 对接上游 · 工单系统）

> 商城系统版本。`GET /api/health` 返回 `version=1.4.0`、`build=20261120b`。

一次重大功能升级：

- **魔方云（KVM 云服务器）**：新增 `cloud` 商品类型，支付后自动在上游创建云主机，交付连接地址 / 系统 / 配置 / 一次性密码；后台「魔方云 · 云主机」与用户中心「我的云主机」支持开机 / 关机 / 重启 / 重置密码。详见[魔方云](/cloud)。
- **魔方财务重新定义 = 对接上游**：新增「魔方财务 · 上游管理」，可维护多条命名上游、测试连接、同步上游产品、加价销售；商品发货配置绑定上游 + 上游产品，支付后自动在上游开通。**移除了本地 Windows 建号端**，不再需要 exe / 8321 端口 / Token。详见[魔方财务（对接上游）](/yulan)与[使用教程](/yulan-guide)。
- **工单系统**：用户提单 / 回复 / 关闭，后台受理 / 回复 / 切换状态，归属严格隔离。详见[工单系统](/tickets)。
- **数据库**：新增 `upstreams / upstream_products / cloud_vms / tickets / ticket_replies` 五张表；`products` 放开 cloud 类型并补 `upstream_id / upstream_product_id` 列；迁移幂等、保留全部历史数据。
- **mock 模式**：站点设置 `upstream_mock=1` 时不联网即可演示开通与交付。

> 升级：下载 `yulan-shop-v140.zip` 覆盖站点（保留 `config/` 与 `data/`），执行 `php bin/migrate.php`，确认 `build=20261120b`，`Ctrl+F5` 强刷后台即可看到新菜单。也可后台「在线更新」一键升级。

## v1.3.0（改名「欲蓝财务」· 多 API · 在线更新）

> 商城系统版本。`GET /api/health` 返回 `version=1.3.0`、`build=20261120a`。与 Windows APP v1.3.0 是两个独立发布物。

系统正式定名 **「欲蓝财务」**：安装默认名、安装向导、后台标题、登录页、文档全部统一。

- **财务魔方多 API 管理**：后台新增「财务魔方 API」菜单，可建多条命名 API（每条指向一台 Windows 服务器，填各自的 IP / 端口 / 口令 / 交付地址，可启停）。商品「发货配置 → 使用哪个 API」可指定走哪条，优先级为 **商品绑定 API > 商品级服务器 > 全局默认**。口令只写不读；删除被占用的 API 会先拦截并可强制解绑。
- **在线更新**：后台「在线更新」菜单可检查官方最新版并一键升级；升级**完整保留**数据库（站点设置 / 主页文案 / 商品订单）、`config/`、已装主题插件与商品图片，只覆盖程序文件，自动备份 + 自动跑幂等迁移。兼容无 PHP curl / zip 扩展的主机。
- **顶部菜单自定义 + 单行修复**：站点设置可独立显示/隐藏「全部器物 / 分类 / 精选」按钮；修复分类多时顶栏换行问题，强制单行。
- **「APP 返回异常」诊断优化**：服务器 IP 误填成网站域名时会明确提示可能填错，并列出 5 项自查清单（网站域名上的 `/api/v1/create-user` 本就 404——该接口在你自己的 Windows 服务器 APP 上，默认 8321 端口）。
- **修复**后台「清除连接口令」按钮失效的问题。

> 升级：到 [Release](https://github.com/yulancloud/yulancloud/releases/tag/v1.3.0) 下载 `yulan-shop-v130.zip` 覆盖站点（保留 `config/` 与 `data/`），执行 `php bin/migrate.php`（幂等，新增 `yulan_apis` 表与 `products.yulan_api_id` 列），强刷后台即可看到新菜单。也可直接在后台「在线更新」里一键升级。

## Windows APP v1.3.0（Python 版打包，独立发布）

> 这是建号端 APP 的版本，与商城系统版本无关，商城端无需改动。用于替代在部分环境会误判管理员而闪退的 Go 版。

- **改为 Python 版打包**：把官方 Python 脚本连同完整 Python 3.11 运行时打包成单个 exe（约 7.4 MB），免安装环境、双击即用。
- **彻底解决闪退**：内嵌 UAC 提权清单（双击自动请求提权）+ 多重管理员判定（`IsUserAnAdmin` + `CheckTokenMembership` 管理员组），域账户 / runas / 计划任务 / 关闭 UAC / 内置 Administrator 都能正确识别，不再误判。
- **编码加固**：修复英文 Windows（cp1252）下中文日志/帮助文本编码崩溃导致的闪退。
- **配置与日志固定在 exe 同目录**：升级只覆盖 exe，配置不丢。
- 升级：到 APP 仓库 Release 下载 `yulan_cube_app.exe` 覆盖即可，`/api/v1/health` 的 `version` 应为 `1.3.0`。
- **注**：该建号端已在 v1.4.0 由「对接上游」取代并移除，此条仅作历史记录保留；新部署请使用[魔方财务（对接上游）](/yulan)。

## Windows APP v1.2.1（独立发布）

> 这是建号端 APP 的修复版本，与商城系统版本无关，商城端无需改动。

- **修复管理员账号被误判闪退**：旧版 Go exe 只认 UAC 提权令牌（`IsElevated`），域账户 / runas / 计划任务 / 关闭 UAC / 内置 Administrator 等场景下，明明是管理员账号却提示「不是管理员」并退出。新版同时接受「Administrators 组成员身份」，行为与 Python 版一致，管理员账号直接双击即可运行。

## v1.2.2

插件运行时版。静态资源版本号升到 `v=20261118a`（健康检查 `build` 为 `20261118a`）。

### 1）删除功能底座，功能全部由插件实现
- 新增 `PluginRuntime`：插件可自带 PHP 代码（存 `data/extensions/plugins/<id>/code/`，Web 不可直接访问），通过 `code/plugin.php` 声明 API 路由、注册钩子、注入前端脚本
- 移除系统内置的 `MailService.php`、`AdminAccountService.php`、`views-features.js` 及主程序里所有相关内置端点与菜单，主程序不再认识任何具体功能
- **以后修功能只更新插件**：逻辑都在插件包里，重传同名插件即覆盖更新，无需再升级系统

### 2）三款功能插件升级 v1.1（自包含，需系统 ≥ v1.2.2）
| 插件 | v1.1 变化 |
| --- | --- |
| SMTP 邮箱验证码注册 | 场景从「后台登录」改为**用户中心注册**：填邮箱 → 收验证码 → 校验通过才注册成功；只有后台白名单邮箱能收码并注册 |
| 多管理员账号 | 全部逻辑自带；修复「点新增管理员没弹窗」（抽屉缺 `is-on` 类） |
| 登录页深色模式 | 纯前端自包含，经运行时注入登录页脚本 |

### 3）兼容与安全
- v1 纯静态插件（无 `code/`）照旧可用；插件 PHP 仅从 `data/` 受控目录加载，禁止路径穿越与符号链接
- 插件 API 走统一声明路由，未声明路径照旧 404；后台插件接口复用店主鉴权与 CSRF 校验

> 升级：下载 `yulan-shop-v122.zip` 覆盖站点（保留 `config/` 与 `data/`），确认 `/api/health` 的 `build` 为 `20261118a`，再到插件市场下载三款 **v1.1** 插件重新上传安装。旧的 v1.0 功能插件在 v1.2.2 上不再提供功能。详见 [v2 插件主题教程](/developer/theme-v2)。


::: warning
**`config/` 文件夹整个都不能删。** 里面有 `config/installed.lock` 安装锁，删掉后站点会被判定为「未安装」：`/install` 安装向导重新出现、全站 API 返回 503「站点尚未安装」，`config/.env` 里的站点地址与支付参数也一起丢失。只覆盖程序文件即可，升级包已排除这些文件。详见 [安装与升级](/deploy/install)。
:::
