商品管理

商品管理 ​

入口：左侧 商品管理。列表支持按名称搜索、按分类 / 状态筛选、上架下架。

一、添加 / 编辑商品 ​

点击「添加商品」打开抽屉表单，字段如下：

字段说明
商品名称必填，最多 80 字
商品类型必填下拉框，见下节
分类必填，来自左侧「分类管理」菜单，见下文第三节
售价（元）必填，如 188.00，内部按分存储
库存必填，整数
颜色 / 规格 / 参数 / 保养可增删的子表，用于前台展示
商品缺点 / 已知不足每行一条，前台详情页「已知不足」栏逐条展示；留空整栏自动隐藏，见第四节
品牌故事 / 商品描述多行文本
发货配置见第五节

新建商品要分两步

刚创建时还没有商品 ID，发货配置需要先保存商品再回来设。保存后在列表点「发货配置」即可。

二、商品类型（三选一） ​

这是添加 / 编辑表单里的「商品类型」下拉框，决定下单后怎么交付：

类型值交付方式
实体商品physical人工发货，需填收货地址、走运费
虚拟商品virtual按发货模板自动发货（卡密、链接等）
欲蓝财务魔方yulan下单后向 Windows APP 下达建号命令，按「连接地址 + 账号」交付

注意

编辑已有商品时，如果不重新选择类型，会保持原类型不变。要改类型必须显式在下拉框里选一次。

三、分类管理 ​

左侧 分类管理 里维护「分类编号 + 分类名称」。删除分类时，若该分类下还有商品会被拒绝，需先转移或删除商品。

四、商品缺点 / 已知不足（v1.1 起） ​

添加 / 编辑商品表单里的多行文本框，每行一条，例如：

text
手工拉坯，同一批次的高度会有 3–5mm 差异，属正常工艺范围。
哑光釉怕骤冷骤热，刚从冰箱取出不宜立刻冲热水。
杯口一圈的釉线会有极轻微的厚薄不均，这是手工施釉的痕迹。
  • 前台商品详情页「已知不足」栏会逐条渲染这些文字，保存后立即生效
  • 留空则整栏自动隐藏，不会留下空面板
  • 该字段存于 products.flaws，旧库升级后执行 php bin/migrate.php 自动补列
  • 未跑迁移时保存商品不会报错（后端会先探测列是否存在），只是缺点内容暂时存不上

为什么要主动写缺点

每件器物都写清已知不足，是这套模板的设计意图：把不完美提前说清楚，减少退货与预期落差。演示数据里 8 件商品都预填了三条，可在后台逐件改成自己的实际情况。

五、发货配置 ​

点商品行的「发货配置」，可设置：

1）发货类型与模板 ​

  • 虚拟商品：填自动发货内容模板，支持占位符（例如卖服务器填 IP / 账号 / 密码，卖网页填链接）。
  • 实体商品：不需要模板，人工发货。
  • 欲蓝财务魔方：下单即创建 Windows 账号，密码平台不存储，交付内容只包含连接地址与账号。

2）欲蓝财务魔方 · 限购与防刷 ​

字段说明
账号限购数量单个账号最多可买几件，0 = 不限购
同 IP 限制开启后同一 IP 也受限购数量约束，防止开多个账号刷单

3）欲蓝财务魔方 · 本商品服务器 ​

每个商品可以配自己的服务器，留空则回退到「欲蓝财务魔方」菜单里的全局默认：

字段说明
服务器 IP本商品专用
端口APP 监听端口
连接账号可选
连接口令只写不读：显示「已配置」徽标；留空不修改，填 __CLEAR__ 清除
连接地址交付给用户看到的地址，如 203.0.113.10 或 rdp.example.com；留空用服务器 IP / 全局默认

全局 vs 商品级

多个商品共用一台服务器时，只在「欲蓝财务魔方」菜单配一次全局默认即可；只有需要分机器时才逐商品填。详见 欲蓝财务魔方。

六、上架 / 下架 ​

列表每行有「上架 / 下架」按钮，状态为 active（在售）或 hidden（下架）。下架商品前台不再展示，历史订单不受影响。

七、常见报错 ​

现象原因
保存报「服务暂时不可用，请稍候再试」旧库子表外键损坏或未跑迁移，执行 php bin/migrate.php，见安装与升级
发货配置打不开 / 提示「加载失败」同上，新列不存在
类型下拉框不出现前端资源被缓存，Ctrl+F5 强刷
后台填了缺点，前台详情页还是旧内容未跑迁移或浏览器缓存；执行 php bin/migrate.php 后 Ctrl+F5 强刷，见版本更新
口令填了看不到值设计如此，只写不读，见后台总览
