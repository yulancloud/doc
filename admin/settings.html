站点设置与其他

站点设置与其他 ​

后台里剩下的日常管理菜单集中在这一篇。注意「站点设置」和「账号与设置」是两个不同页面。

一、站点设置 ​

左侧「站点设置」：管理前台展示的站点文案（站点名、公告、页脚等）。

  • 文案保存在数据库，保存后立即生效
  • 不需要改 HTML、不需要重启服务
  • 支付参数不在这里，去 易支付配置

可配置的文案包括：站点名称 / 英文名、首页眉标（如 EST. 2019 · 上海静安）、首页主标题、首页副标题、商品区标题、公告条、页脚说明 / 版权 / 备案 / 联系方式、站点介绍、浏览器标题与描述等。

v1.1 起前台文案动态生效

旧版有两处写死：顶栏分类标签写死了「家居 / 桌面 / 随行」，首页「在售」区大标题写死了「八件在售器物……」，后台改了也不生效。v1.1 已修复：

  • 分类标签：顶栏、页脚、商品详情页面包屑统一由 /api/catalog 渲染，后台「分类管理」改名、隐藏、新增分类，前台同步变化
  • 首页文案：主标题 / 副标题 / 商品区标题都绑定后台设置，打字动画播完后会停在后台设置的新文字上（旧版动画结束会用 HTML 里的旧文案覆盖回去）

改完前台仍显示旧内容？先 Ctrl+F5 强刷（资源版本 v=20261116e），再看 常见问题 的 Q18。详见 版本更新。

二、运费设置 ​

左侧「运费设置」：只管运费金额与包邮门槛，独立于站点设置。实体商品走运费，虚拟 / 欲蓝商品不涉及。

三、虚拟商品发货 ​

左侧「虚拟商品发货」：逐个虚拟商品设置各自的自动发货内容模板（卡密、链接等）。与商品管理里的「发货配置」是同一份数据的另一个入口，按商品维度配置。

四、魔方财务 · 上游管理 ​

左侧「魔方财务 · 上游管理」：添加上游（finance 对接上游财务系统 / cloud 对接魔方云 KVM）、测试连接、同步上游产品并维护成本价与上架状态。商品在「发货配置」里绑定上游 + 上游产品，支付后自动开通。

  • 演示 / 试用可在站点设置开启 mock 模式（upstream_mock=1），不联网即可跑通开通与交付。
  • 详见 魔方财务（对接上游）、魔方财务使用教程、魔方云。

注意

上游 API 密钥「只写不读」，页面只显示「已配置」徽标：留空 = 不修改，填 __CLEAR__ = 清除。详见商品管理。

五、工单管理 ​

左侧「工单管理」：查看全部工单、按状态筛选、查看详情、回复客户、切换状态（待处理 / 处理中 / 已回复 / 已关闭）。用户在用户中心「工单」标签提交与回复。详见 工单系统。

五、用户管理 ​

左侧「用户管理」：查看注册用户、停用 / 恢复账号。

  • 停用后该用户无法登录，现有会话立即失效
  • 停用前会二次确认

六、评价管理 ​

左侧「评价管理」：审核前台商品评价。前端渲染评价文本时统一做转义，不存在存储型 XSS。

七、账号与设置（改密） ​

左侧「账号与设置」：查看当前登录账号、修改密码。

改密影响其他设备

改密后该账号在其他设备上的登录会全部失效，当前会话保留。首次登录后若仍是初始密码，系统会提示尽快修改。

八、操作日志 ​

左侧「操作日志」，仅店主（owner）可见，店员看不到该菜单并记录后台敏感操作。排查「谁改了配置」时看这里。
