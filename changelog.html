版本更新

版本更新 ​

这里记录每个版本相对上一版的变化与升级要点。升级前请先备份 data/shop.sqlite 与 config/.env。

v1.6.0（双主题 · 双品牌 · 5 种支付方式） ​

商城系统版本。GET /api/health 返回 version=1.6.0、build=20261128a。

核心变化：把「像玩具」的手作器物表层，换成可切换的正经财务 / 云主机界面。

  • 双主题切换：后台「站点设置 → 界面风格」可选「经典」（原手作器物风，默认）或「创新」（智简魔方 v10 / TDesign 蓝白风）。切换即时生效，两主题资源完全隔离。
  • 创新主题（public/innovative/）：从智简魔方 v10 真实源码提取设计语言（品牌蓝 #0052d9、白底卡片、统计大数字）。含首页、注册 / 登录（分栏布局）、控制台（左侧菜单 + 顶栏 + 卡片）；控制台接入订单、云主机、财务魔方账号、工单、余额、账号设置全部视图，全部走真实 API。
  • 双品牌共存：站点设置新增「主品牌名 / 副品牌名」，默认「欲蓝财务魔方」与「魔方财务」，创新主题登录页同时呈现。
  • 5 种支付方式配置框架：新增易支付、微信 H5、微信官方支付、支付宝支付、支付宝当面付（另有余额支付）。官方渠道需企业资质，未配置完整时前台自动置灰、下单回退易支付对应通道——永远有可用支付。后台新增「支付方式（5 种）」菜单；密钥只写不读。
  • 无新增表、无 schema 变更，纯 KV 设置 + 静态资源，零迁移成本。

升级：下载 yulan-shop-v160.zip 覆盖站点（保留 config/ 与 data/），确认 build=20261128a 后强刷后台。详见更新说明。

v1.5.0（内置智简魔方 v10 真实协议 · 修复对接上游 404） ​

商城系统版本。GET /api/health 返回 version=1.5.0、build=20261122a。

核心修复：对接真实魔方上游全部 HTTP 404 的问题。

v1.4.x 的「对接上游」用的是一套自造协议（/api/v1/products、Bearer api_key、/api/v1/orders 等），mock 演示能跑，但连真实智简魔方 v10 / 魔方云时全部 404。为此我们研读了智简魔方 v10 开源源码（AuthController / SupplierModel::apiAuth / idcsmart_api_curl / UpstreamLogic / ResModuleLogic），据此重做对接：

  • 新增 MofangApi 适配器：完整实现真实协议。
    • 两阶段鉴权：先 POST /api/v1/auth {username,password} 换 JWT（老财务为 /zjmf_api_login），再以 Authorization: Bearer <JWT> 调业务接口；JWT 缓存 2 小时，遇 401/405 自动重登重试。
    • 真实端点：产品 GET /api/v1/product（老财务 /api/product/list）；下单 console/v1/cart → cart/settle → pay（老财务 cart/add_to_shop → cart/settle → apply_credit）；操作 POST /provision/default。
    • 正确解析 {status:200, data:{list}} 响应结构。
  • 支持三种上游协议：v10（新魔方云/财务，推荐）、finance（老财务 zjmf_api）、whmcs（代理插件）。后台「上游管理」新增「上游协议」下拉，一般只需选协议、无需手填路径。
  • 默认路径修正 + 存量自动迁移：upstreams 新增 api_type 列；迁移会把旧的错误默认路径自动改为真实端点，且不覆盖管理员自定义路径。
  • 沿用 v1.4.1 的在线更新长超时与解除执行时间限制修复。

升级：下载 yulan-shop-v150.zip 覆盖站点（保留 config/ 与 data/），执行 php bin/migrate.php，确认 build=20261122a 后强刷后台。详见魔方财务（对接上游）与使用教程。

v1.4.1（修复补丁 · 在线更新与对接上游） ​

商城系统版本。GET /api/health 返回 version=1.4.1、build=20261121a。这是一个纯修复补丁，不新增表、不改存量数据结构。

修复 v1.4.0 上线后反馈的两类问题：

  • 后台在线更新超时：
    • 前台把更新检查 / 执行接口的超时从默认 15 秒放宽到 180 秒，按钮增加「可能需要几分钟、请勿关闭或重复点击」提示。
    • 后端更新执行前解除 PHP 执行时间限制（set_time_limit(0) / ignore_user_abort(true)），避免写文件写到一半被 30 秒上限杀掉。
    • 「检查更新」阶段的 GitHub 请求改用短超时快速失败，两个端点不再串行各等 120 秒，解决「请求超时」。
  • 对接上游核心问题：
    • 开通时机统一：绑定上游的 yulan 商品从「下单即开通」改为支付成功后开通，与 cloud 一致；未付款不再触发上游扣费 / 开资源，也不会因事务回滚留下「钱付了没账号」的半成品。
    • 账号密码免填：上游模式下账号 / 密码由上游返回，购物车不再强制用户填写 Windows 账号密码；未绑定上游的存量商品仍保留旧流程（兼容）。
    • 协议可配置：上游新增 auth_mode（bearer / basic / query / none）、api_base_path、产品 / 开通 / 操作路径、价格单位 price_is_cents 等字段，管理员可按真实魔方云 / 魔方财务 API 填写鉴权方式与路径，不再写死自造协议。
    • 安全与健壮性：接口地址禁止内网 / 回环地址（收紧 SSRF）；兼容真实上游多种 IP / 密码字段名；修复 financial_id 重复赋值与交付变量覆盖隐患。

升级：下载 yulan-shop-v141.zip 覆盖站点（保留 config/ 与 data/），执行 php bin/migrate.php（幂等，可重复跑），确认 build=20261121a 后 Ctrl+F5 强刷后台即可。

v1.4.0（魔方云 · 对接上游 · 工单系统） ​

商城系统版本。GET /api/health 返回 version=1.4.0、build=20261120b。

一次重大功能升级：

  • 魔方云（KVM 云服务器）：新增 cloud 商品类型，支付后自动在上游创建云主机，交付连接地址 / 系统 / 配置 / 一次性密码；后台「魔方云 · 云主机」与用户中心「我的云主机」支持开机 / 关机 / 重启 / 重置密码。详见魔方云。
  • 魔方财务重新定义 = 对接上游：新增「魔方财务 · 上游管理」，可维护多条命名上游、测试连接、同步上游产品、加价销售；商品发货配置绑定上游 + 上游产品，支付后自动在上游开通。移除了本地 Windows 建号端，不再需要 exe / 8321 端口 / Token。详见魔方财务（对接上游）与使用教程。
  • 工单系统：用户提单 / 回复 / 关闭，后台受理 / 回复 / 切换状态，归属严格隔离。详见工单系统。
  • 数据库：新增 upstreams / upstream_products / cloud_vms / tickets / ticket_replies 五张表；products 放开 cloud 类型并补 upstream_id / upstream_product_id 列；迁移幂等、保留全部历史数据。
  • mock 模式：站点设置 upstream_mock=1 时不联网即可演示开通与交付。

升级：下载 yulan-shop-v140.zip 覆盖站点（保留 config/ 与 data/），执行 php bin/migrate.php，确认 build=20261120b，Ctrl+F5 强刷后台即可看到新菜单。也可后台「在线更新」一键升级。

v1.3.0（改名「欲蓝财务」· 多 API · 在线更新） ​

商城系统版本。GET /api/health 返回 version=1.3.0、build=20261120a。与 Windows APP v1.3.0 是两个独立发布物。

系统正式定名 「欲蓝财务」：安装默认名、安装向导、后台标题、登录页、文档全部统一。

  • 财务魔方多 API 管理：后台新增「财务魔方 API」菜单，可建多条命名 API（每条指向一台 Windows 服务器，填各自的 IP / 端口 / 口令 / 交付地址，可启停）。商品「发货配置 → 使用哪个 API」可指定走哪条，优先级为 商品绑定 API > 商品级服务器 > 全局默认。口令只写不读；删除被占用的 API 会先拦截并可强制解绑。
  • 在线更新：后台「在线更新」菜单可检查官方最新版并一键升级；升级完整保留数据库（站点设置 / 主页文案 / 商品订单）、config/、已装主题插件与商品图片，只覆盖程序文件，自动备份 + 自动跑幂等迁移。兼容无 PHP curl / zip 扩展的主机。
  • 顶部菜单自定义 + 单行修复：站点设置可独立显示/隐藏「全部器物 / 分类 / 精选」按钮；修复分类多时顶栏换行问题，强制单行。
  • 「APP 返回异常」诊断优化：服务器 IP 误填成网站域名时会明确提示可能填错，并列出 5 项自查清单（网站域名上的 /api/v1/create-user 本就 404——该接口在你自己的 Windows 服务器 APP 上，默认 8321 端口）。
  • 修复后台「清除连接口令」按钮失效的问题。

升级：到 Release 下载 yulan-shop-v130.zip 覆盖站点（保留 config/ 与 data/），执行 php bin/migrate.php（幂等，新增 yulan_apis 表与 products.yulan_api_id 列），强刷后台即可看到新菜单。也可直接在后台「在线更新」里一键升级。

Windows APP v1.3.0（Python 版打包，独立发布） ​

这是建号端 APP 的版本，与商城系统版本无关，商城端无需改动。用于替代在部分环境会误判管理员而闪退的 Go 版。

  • 改为 Python 版打包：把官方 Python 脚本连同完整 Python 3.11 运行时打包成单个 exe（约 7.4 MB），免安装环境、双击即用。
  • 彻底解决闪退：内嵌 UAC 提权清单（双击自动请求提权）+ 多重管理员判定（IsUserAnAdmin + CheckTokenMembership 管理员组），域账户 / runas / 计划任务 / 关闭 UAC / 内置 Administrator 都能正确识别，不再误判。
  • 编码加固：修复英文 Windows（cp1252）下中文日志/帮助文本编码崩溃导致的闪退。
  • 配置与日志固定在 exe 同目录：升级只覆盖 exe，配置不丢。
  • 升级：到 APP 仓库 Release 下载 yulan_cube_app.exe 覆盖即可，/api/v1/health 的 version 应为 1.3.0。
  • 注：该建号端已在 v1.4.0 由「对接上游」取代并移除，此条仅作历史记录保留；新部署请使用魔方财务（对接上游）。

Windows APP v1.2.1（独立发布） ​

这是建号端 APP 的修复版本，与商城系统版本无关，商城端无需改动。

v1.2.2 ​

插件运行时版。静态资源版本号升到 v=20261118a（健康检查 build 为 20261118a）。

1）删除功能底座，功能全部由插件实现 ​

  • 新增 PluginRuntime：插件可自带 PHP 代码（存 data/extensions/plugins/<id>/code/，Web 不可直接访问），通过 code/plugin.php 声明 API 路由、注册钩子、注入前端脚本
  • 移除系统内置的 MailService.php、AdminAccountService.php、views-features.js 及主程序里所有相关内置端点与菜单，主程序不再认识任何具体功能
  • 以后修功能只更新插件：逻辑都在插件包里，重传同名插件即覆盖更新，无需再升级系统

2）三款功能插件升级 v1.1（自包含，需系统 ≥ v1.2.2） ​

插件v1.1 变化
SMTP 邮箱验证码注册场景从「后台登录」改为用户中心注册：填邮箱 → 收验证码 → 校验通过才注册成功；只有后台白名单邮箱能收码并注册
多管理员账号全部逻辑自带；修复「点新增管理员没弹窗」（抽屉缺 is-on 类）
登录页深色模式纯前端自包含，经运行时注入登录页脚本

3）兼容与安全 ​

  • v1 纯静态插件（无 code/）照旧可用；插件 PHP 仅从 data/ 受控目录加载，禁止路径穿越与符号链接
  • 插件 API 走统一声明路由，未声明路径照旧 404；后台插件接口复用店主鉴权与 CSRF 校验

升级：下载 yulan-shop-v122.zip 覆盖站点（保留 config/ 与 data/），确认 /api/health 的 build 为 20261118a，再到插件市场下载三款 v1.1 插件重新上传安装。旧的 v1.0 功能插件在 v1.2.2 上不再提供功能。详见 v2 插件主题教程。

v1.2.1 ​

功能插件底座版。在 v1.2 基础上新增三个"装上就生效"的功能插件底座。系统包仍不含 Windows APP 的 exe（到 Windows APP 仓库 下载）。

1）三款功能插件（到插件市场按需安装） ​

三个功能默认不开启，到 插件市场 下载对应插件，在后台「主题与插件」上传安装后启用；不装不出现。

  • SMTP 邮箱验证码登录（smtp-login）：后台多出「邮件服务器配置」，登录页新增「邮箱验证码」标签。纯 PHP SMTP 客户端，支持 STARTTLS / SSL / 免认证 relay；密码只写不读，验证码 5 分钟有效、最多 5 次尝试、用后即焚，白名单外邮箱混淆返回。需在「多账号管理」给管理员绑定邮箱。
  • 登录页深色模式（login-dark-mode）：登录页右上角出现明暗切换按钮，选择记在浏览器本地。纯前端。
  • 多管理员账号（multi-admin）：后台多出「多账号管理」，店主可新增第二个、第三个管理员，支持编辑 / 启停 / 重置密码 / 删除。一次性密码只显示一次，禁止删除当前账号与最后一个店主。

2）沿用 v1.2 能力 ​

用户中心「控制台」改欲蓝魔方账号、后台主题/插件上传、干净安装默认 0 分类 0 商品，均保持不变。

  • 进入商品详情可查看连接地址、账号等信息，并可修改登录用户名 / 密码

  • 改号有独立限流 + 审计日志，口令全程不落库、不进日志明文
  • 需配套升级 Windows APP 到 v1.2（新增 /api/v1/update-user）

2）后台上传主题 / 插件（v2 扩展机制） ​

  • 后台「系统 → 主题与插件」上传 zip 即装，支持启用 / 停用 / 设为当前主题 / 卸载
  • 主题只写 CSS 变量覆盖，服务端动态输出 GET /api/theme.css，升级覆盖 Release 也不丢；亮 / 暗两套自动提升选择器特异性
  • 插件 files/ 静态资源装到 public/plugins/<id>/，零侵入、不建表
  • 纯 PHP 解析 ZIP，不依赖 ZipArchive 扩展；多重安全校验，危险包一律拒绝
  • 更简单的制作方式见 v2 插件主题教程（后台上传）；旧的手动改 CSS 方式见 v1 插件主题教程
  • 也可到 插件市场 下载现成插件

3）干净安装默认 0 分类 / 0 商品 ​

  • 全新安装不再预置演示分类与商品；需要演示数据时 php bin/init_db.php --with-demo 显式开启

text

      ↓

      ↓

      ↓

      ↓

注意
